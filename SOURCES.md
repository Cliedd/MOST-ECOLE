# SOURCES OFFICIELLES – MOST ÉCOLE

> Agent 1 (RechercheOfficielle) — Inventaire des sources légales utilisables

## Principe directeur

Seuls les référentiels pédagogiques officiels publiés par les autorités compétentes de la
Fédération Wallonie-Bruxelles (FWB), le SEGEC et WBE sont utilisés comme base curriculaire.
Les manuels commerciaux présents dans `/home/ryzen/Vidéos/` (Van In, De Boeck, Plantyn) ne
sont **pas reproduits** sur la plateforme — ils servent uniquement à aligner la structure
pédagogique sur ce que les élèves connaissent déjà via leurs cours.

- **Langues modernes** (Anglais, Néerlandais, Allemand, Espagnol)
- **Éducation physique et sportive**
- **Arts plastiques / Musique**

## 4. Plan d'action pour le contenu manquant

1. **Court terme** : Utiliser les référentiels FWB/SEGEC pour structurer les UAA dans
   la table `curriculum_expectations`. Les attentes officielles sont librement
   consultables et citables avec mention de source.

2. **Moyen terme** : Recruter des enseignants certifiés pour créer du contenu
   original aligné sur les référentiels. Chaque cours doit mentionner l'UAA couvert.

3. **Long terme** : Partenariats avec ULiège/UCLouvain/UNamur pour le contenu
   concours médecine. Les annales officielles étant publiques, elles peuvent
   être reférencées avec lien direct.
